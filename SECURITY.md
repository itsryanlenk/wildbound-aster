# Security policy

Do not publish passwords, access tokens, personal save backups, private contact details, or unredacted browser/network logs in issues.

For a security-sensitive report, use GitHub private vulnerability reporting if the repository's Security tab offers it. If that option is unavailable, open an issue asking for a private reporting channel without including exploit details or sensitive data.

The standalone game is a static distribution with local-browser saves. It should never need a server secret, GitHub token, or account password to play. Public builds must not include development credentials or original private histories.

Reports are reviewed on a best-effort basis. No response-time or exhaustive device-support guarantee is made.
