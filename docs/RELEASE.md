# Wildbound — Field Edition 04

An original browser creature adventure with local saves, real-time combat and capture, 151 companions, eight beacon trials, and nine regions.

## Downloads

- **wildbound-game-v0.4.0.zip** — prebuilt game, all runtime assets, local server and license notices.
- **wildbound-launch-trailer.mp4** — finished 50-second 720p launch film.
- **wildbound-orchestral-score.mp3** — Aster Takes Flight, original synthesized orchestral score.
- **wildbound-launch-poster.png** — launch artwork.
- **wildbound-trailer-source.zip** — editable trailer production with source clips; no font binaries.
- **SHA256SUMS.txt** — SHA-256 checksums for these assets.

Serve the game folder over HTTP(S), or run its included `serve.mjs` with Node.js. Keep local saves backed up through Settings. Different hosts do not automatically share browser saves.

The original project license is MIT. Bundled dependencies, including Remotion, retain their own terms; see NOTICE and the included licenses.

This release recovers the complete **prebuilt** game and editable trailer materials. It does not include the original unbundled game source/lockfile. Package verification is distinct from historical gameplay tests. A complete physical-device QA matrix is not claimed.
