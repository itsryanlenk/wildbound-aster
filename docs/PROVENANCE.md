# Recovery provenance

## Included

The recovered Field Edition 04 game ZIP contains the complete prebuilt HTML, JavaScript, CSS, creature art, regional art, audio and offline worker. Both the game ZIP and trailer-source ZIP passed ZIP CRC checks when recovered. The final trailer is an H.264/AAC MP4. The editable trailer contains seven pre-rendered gameplay clips and its actual editing and synthesis scripts.

The source clips are deterministic captures of the original game engine using scripted fixtures and inputs. They are not a continuous screen recording of someone completing the campaign. The final video has editorial captions. The orchestral score was synthesized locally, not generated by ElevenLabs or recorded by a live orchestra.

## Missing

The unbundled game TypeScript/React checkout, complete original dependency lock, and original gameplay-test sources were not in the recoverable attachments. This repository does not claim to contain them or fabricate replacements. `game/assets/` contains built code, not authoring source. Restoring the original checkout is a separate task.

`trailer/render-gameplay.mjs` is a preserved, portable recapture recipe, but requires that missing checkout via `WILDBOUND_GAME_SOURCE`. The ordinary trailer edit/re-render works from the included MP4 clips without it.

## Changes in the recovery package

The public package uses relative paths rather than the original private working directories. Old diagnostic dumps and production-history references are excluded. Fonts are not redistributed; local system fallback or user-supplied local font paths are used by re-renders. Consequently a new render may not be pixel-identical to the supplied master. No claim is made that the amended authoring scripts have re-rendered the full master in this recovery session.
