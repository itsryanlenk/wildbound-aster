# Changelog

## 0.4.0 — Field Edition 04 distribution recovery — 2026-10-08

Packaging changes in this repository:

- Recovered and integrity-checked the complete playable distribution and final launch media.
- Added an MIT license for original material and separate dependency notices.
- Added setup, player, hosting, save, privacy, security and provenance documentation.
- Added CI, optional GitHub Pages deployment, release publishing, integrity checks and a privacy preflight.
- Removed machine-specific paths, font binaries, stale private diagnostics and source-history references from the redistributable trailer project.
- Made trailer paths relative; supplied captures can be edited without the missing game source.

Gameplay improvements recorded for the recovered Field Edition 04 build (not newly implemented by this packaging pass):

- Notifications and conversations use designated space outside the arena.
- Ranger walking follows distance travelled and includes directional neutral/idle poses.
- Overworld creatures are smaller than their battle presentation.
- Existing splash art is animated and respects reduced motion.
- XP, targeted Growth Candy, level-cap displays and evolution/reward ordering were revised.
